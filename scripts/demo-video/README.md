# مقاطع إيت التسويقيّة — دليل التشغيل

ثلاثة مقاطع MP4 من لقطاتٍ حقيقيّة للتطبيق الشغّال. **لا واجهة معاد بناؤها،
ولا بيانات مخترَعة على الشاشة، ولا تعديل ألوانٍ بعد الالتقاط.**

كُتبت هذه السكربتات في بيئةٍ محجوبةٍ عن القاعدة، فلم تُشغَّل ولم تُختبر
حيًّا. الخطوة ٢ أدناه موجودةٌ لهذا السبب: تُثبّت المحدِّدات قبل أن تعتمد عليها.

---

## المتطلّبات

```bash
npm i -D playwright
npx playwright install chromium
```

`ffmpeg` يأتي مع Playwright — `compose.sh` يجده تلقائيًّا. إن لم يجده:
`export FFMPEG=/path/to/ffmpeg`.

## المتغيّرات

| المتغيّر | الشرح | مثال |
|---|---|---|
| `BASE_URL` | عنوان التطبيق المحليّ | `http://localhost:3000` |
| `DB_URL` | رابط القاعدة لتشغيل SQL | `postgresql://…` |
| `STAFF_USER` · `STAFF_PASS` | حساب شركاء **اختباريّ** | — |
| `DEMO_SLUG` | مُعرّف المطعم التجريبيّ | `alasalah` |
| `DEMO_BRANCH_ID` | معرّف الفرع (تطبعه `seed.sql`) | `d3m0…0002` |
| `SHOTS_DIR` · `OUT_DIR` | مجلّدا اللقطات والمخرجات | `screenshots` · `out` |

## الخطوات بالترتيب

### ١ — البذرة

استبدل `:owner_uid` بمعرّف حساب الشركاء الاختباريّ من `auth.users` — الملكيّة
هي ما يفتح لك `/dashboard` على هذا المطعم:

```bash
psql "$DB_URL" -v owner_uid="'<UUID-حسابك-الاختباريّ>'" \
     -f scripts/demo-video/seed.sql
```

يطبع `demo_branch_id` — ضعه في `DEMO_BRANCH_ID`.

**العزل: `is_active = true` مع `is_canary = true`** — وهذه التركيبة ثبتت
بالتجربة على المحاكاة لا بالتقدير:

- `is_active = false` **يقتل الرحلة كلّها**: محفّز `enforce_platform_open()`
  يرفض أيّ إدراجٍ في الطابور بـ`P0002 «المطعم متوقّف حاليًا»`. جرّبته فسقط.
- والإخفاء يأتي من `is_canary`: `public-cache.ts:54-55` و`search/page.tsx:18`
  يُرشِّحان `.eq("is_canary", false)`. فالمطعم لا يظهر في الاكتشاف ولا البحث
  لأيّ عميلٍ حقيقيّ، وتعمل صفحته ولوحاته بالرابط المباشر.

وساعات الدوام `00:00–23:59` عمدًا كي لا يسقط الانضمام لو التقطتَ ليلًا.

**السكربت قابلٌ لإعادة التشغيل**: صفوف الطابور تُحذف وتُدرَج من جديد (محصورًا
بفرع العرض)، لأنّ `waitlist_entries` عليه قيد `EXCLUDE` مؤجَّل لا يقبله
`ON CONFLICT` حَكَمًا — `55000`.

### ٢ — تثبيت المحدِّدات (لا تتخطَّها)

```bash
BASE_URL=http://localhost:3000 node scripts/demo-video/discover.mjs
```

يكتب `discovered.json` بكلّ زرٍّ وحقلٍ ظاهر. قارنه بـ`selectors.json` وصحّح ما
يلزم — خصوصًا قسمَي `partners` و`customer`، وهما اللذان لم أستطع قراءتهما من
الشيفرة الساكنة بثقة. أمّا `reception` فمحدِّداته مستخرَجةٌ من الشيفرة وموثّقٌ
سطرُ كلٍّ منها.

### ٣ — الالتقاط

```bash
BASE_URL=http://localhost:3000 \
DEMO_SLUG=alasalah DEMO_BRANCH_ID=<من الخطوة ١> \
STAFF_USER=… STAFF_PASS=… \
node scripts/demo-video/capture.mjs
```

يفتح سياقين متوازيين — جوّال العميل (390×844) ولوحة الاستقبال (1440×900)،
كلاهما `deviceScaleFactor: 3` — ويُجلِس من أمام العميل بين اللقطات ليصنع
«تقدّم الدور» و«حان دورك» **فعلًا** لا تمثيلًا.

أيّ لقطةٍ تتعذّر تُسجَّل بالاسم والسبب في `screenshots/capture-report.json`
و**لا يُصنع لها بديل**.

### ٤ — المراجعة قبل التركيب

افتح `screenshots/` وتصفّحها بعينك. تأكّد أنّ كلّ لقطةٍ من «مطعم الأصالة» ولا
اسمَ ولا رقمَ حقيقيّ ظهر في أيّ إطار.

### ٥ — التركيب

```bash
bash scripts/demo-video/compose.sh
```

يُخرج `out/customer.mp4` · `out/reception.mp4` · `out/owner.mp4` —
1080×1920 · 30fps · H.264 · بلا صوت.

### ٦ — التنظيف

```bash
psql "$DB_URL" -f scripts/demo-video/cleanup.sql
```

يطبع أربعة أعداد — **يجب أن تكون كلّها صفرًا**.

## ما يرسمه `compose.sh` وما لا يرسمه

**يرسم:** الخلفية الكريميّة `#F7F0E4` · إطار اللقطة · شاشتَي العنوان والخاتمة ·
سطر التعليق العربيّ **أسفل** اللقطة لا فوقها. عناصر تأطيرٍ استثنيتَها صراحةً.

**لا يرسم:** ولا بكسل من واجهة المنصّة. اللقطة تُركَّب كما خرجت: بلا تعديل
لونٍ ولا تشبّعٍ ولا حدّةٍ ولا اقتصاصٍ للمحتوى — التكبير الوحيد هو زوم
`1.00 → 1.04` على لقطات «بعد» لجذب العين، وهو حركة كاميرا لا تغيير محتوى.

الألوان مأخوذةٌ من `docs/BRAND-COLORS.md`: `#781e0c` و`#f7f0e4` — مطابقةٌ لما
حدّدتَه. والخطّ يبحث عن IBM Plex Sans Arabic (خطّ المشروع في
`src/app/layout.tsx`) ثمّ Noto Naskh؛ وإن لم يجد خطًّا عربيًّا **يتوقّف
ويخبرك** ولا يسقط إلى خطٍّ رديء بصمت.

## نقاط أتوقّع أن تحتاج تعديلًا عندك

1. **نصّ العربيّة في `drawtext`** — بعض بُنى ffmpeg بلا `libfribidi` تعرض
   العربيّة مقطّعةً أو معكوسة. تحقّق من أوّل مقطع؛ إن ظهرت مكسورة فالحلّ
   توليد التعليقات صورًا PNG بدل `drawtext`. أخبرني وأكتبها لك.
2. **إطار الجوّال** — الحاليّ حافّةٌ رفيعة بلون العلامة. إن أردت إطارًا أدقّ
   (نوتش وأزرار) فهو صورة PNG شفّافة تُركَّب فوق اللقطة، أرسلها وأدمجها.
3. **مدّة المقاطع** — بالتوقيتات الحاليّة: العميل ≈ ٢٧ث، الاستقبال ≈ ٣٢ث،
   المالك ≈ ٣٥ث. المالك ضمن نطاقك ٣٠–٤٥، والعميل أقصر قليلًا — إن أردته أطول
   ارفع مدّة اللقطات العاديّة من ٣ إلى ٣٫٥.
4. **`11-tv.png`** تحتاج `DEMO_BRANCH_ID`؛ بدونه تُسجَّل «متعذّرة» ولا تُختلق.
